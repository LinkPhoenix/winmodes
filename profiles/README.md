# Mode profiles

Generated by `tools/build-profiles.ps1` from `data/db/*.json`, `data/protected.json`, `research/oss-optimizers/tweaks-consensus.json` and the hand-written `modes.manual.json`. Do not edit `code.json`, `work.json`, `game.json` or `baseline.json` by hand: edit `modes.manual.json` or the knowledge base, then regenerate.

```bash
pwsh -NoProfile -File tools/build-profiles.ps1
```

These files are declarative. No engine applies them yet.

## Files

| File | Role |
|---|---|
| `modes.manual.json` | User-owned: label, intent, power plan, WSL/Docker behaviour, apps to close or launch, and services never to stop (`keepServices`) |
| `baseline.json` | Opt-in tweaks applied once and shared by every mode: low risk, reversible, applied by at least 7 of the 12 code-verified optimizers |
| `code.json`, `work.json`, `game.json` | One generated profile per mode |

## Selection rules

A service is stopped and set to Manual in a mode only if all of these hold:
- its mode score is 0 or 1;
- it was verified by a fetched web source (local-only evidence is not enough);
- its risk is not `high` or `never-touch`;
- it is not listed in `data/protected.json` or in `keepServices`;
- it is not Disabled;
- stopping it has an effect: it starts automatically or is running.

A service is started when its mode score is 3 and its start mode is Manual.

Mode tweaks are the reversible, code-verified tweaks with relevance 3 for that mode. The tweak types allowed in a mode are registry, service, power plan and scheduled task. Appx removal, program uninstall and Windows features are excluded.

`apps.suggestedToClose` lists startup apps scored 0 for the mode. Protected apps are left out. These are suggestions only: the engine closes only what the user copies into `apps.close`.
