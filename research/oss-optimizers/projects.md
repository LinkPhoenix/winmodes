I found no mature OSS project that switches between reversible Code/Work/Game modes. `gh search repos` returned nothing relevant. Process Lasso (closed source) has per-process profiles. Microsoft Game Mode and PowerToys handle only small parts of this.

## Per-project notes

- **winutil**: this has the best data model to copy. Each tweak in `tweaks.json` lists `registry[] {Path, Name, Type, Value, OriginalValue}`, `service[] {Name, StartupType, OriginalType}`, `ScheduledTask[] {Name, State, OriginalState}`, `InvokeScript`/`UndoScript`, and `appx`. `WPFTweaksServices` sets about 100 services to Manual, and a few to Disabled: DiagTrack, CscService, SharedAccess. The "OriginalValue" field stores Microsoft's default, not the value the machine actually had, so undo goes back to defaults.
- **Win11Debloat**: small, auditable .reg files, each paired with one in `Regfiles/Undo/`. The AI entries cover Recall, Copilot, Click to Do, and Notepad/Paint/Edge AI. The Sysprep variants target the default user. `Config/Apps.json` gives each app a "Recommendation" (safe/…) and `SelectedByDefault`. That is a good pattern for safety tiers.
- **Atlas**: the YAML tweaks are grouped as debloat/misc/networking/performance/privacy/qol/security. Its optional toggles, run from the Atlas desktop folder, include turning off Defender, mitigations, VBS and updates. It is the main source of the high-risk tweaks, and it is not supported for security-conscious users.
- **Sophia**: the cleanest reversible API. Every function takes `-Enable/-Disable` or `-Show/-Hide`, and it checks the OS build before acting. The downside is that it rejects modified systems.
- **privacy.sexy**: every script has explicit `code` + `revertCode` and a recommendation level (standard/strict). This is the best model for undo metadata.
- **Winhance** (code-verified): each setting in `Features/Optimize/Models/*.cs` is a C# record with `Id`, `GroupName`, registry entries carrying both `DefaultValue` and `RecommendedValue` (421 each), `IsRecommended`, `Warning`, and explicit dependencies (`ParentSettingId`, `DependentSettingId`/`RequiredSettingId`, e.g. Memory Integrity requires VBS, Prefetch requires SysMain). It exposes VBS/Memory Integrity off, Windows Update pause and NoAutoUpdate modes, MMCSS, Nagle, MPO, svchost split, power-plan templates via powercfg. It does **not** disable Defender, contrary to the first pass. Closest UX to ours.
- **optimizer / W4RH4WK / Windows10Debloater** (code-verified) **/ LeDragoX** (not read): archived and aggressive. optimizer and W4RH4WK set `DisableAntiSpyware` and `NoAutoUpdate`; W4RH4WK also disables memory compression. Use them only as a list of what not to do.
- **ReviOS** (code-verified): Defender disable is an install option (`win-sxs.yml`, `disable-defender`), and `final.yml` runs `Disable-MMAgent -mc` (memory compression off) unconditionally. It does not disable Spectre mitigations: `FeatureSettingsOverride` appears only in `revert.yml`.
- **tiny11builder** (code-verified): `tiny11maker.ps1` removes appx and sets policy keys offline; `tiny11Coremaker.ps1` also removes the Defender package and disables `wuauserv` via RunOnce. Image-time only.
- **CrapFixer** (code-verified, builtbybel active tool): small per-feature classes (Recall, Click to Do, Copilot, ads, Edge policies, GameDVR, PowerThrottling, NetworkThrottling, SystemResponsiveness, TaskbarEndTask). No security-weakening features found.
- **winutil applications.json** (code-verified): 236 winget/choco install entries (41 Development, incl. Docker Desktop); an installer catalog, not tweaks. `feature.json` enables WSL, Hyper-V and Sandbox. `preset.json` has Standard (12), Minimal (4), Advanced (17) presets.
- **tiny11builder**: works on install images only. It is not usable at runtime.
